# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/csv-sync-portal.git
```

---

## 2️⃣ Frontend Setup

```bash
cd read_write_csv_v2_fe
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

## 3️⃣ Backend Setup

Open backend project in Eclipse / STS.

Run:

```bash
mvn clean install
mvn spring-boot:run
```

Backend runs on:

```bash
http://localhost:8080
```

# 📮 API Endpoints

| Method | Endpoint               | Description       |
| ------ | ---------------------- | ----------------- |
| POST   | `/api/csv/upload`      | Upload CSV file   |
| GET    | `/api/csv/read`        | Read CSV data     |
| POST   | `/api/csv/add`         | Add CSV record    |
| PUT    | `/api/csv/update/{id}` | Update CSV record |
| DELETE | `/api/csv/delete/{id}` | Delete CSV record |
| GET    | `/api/csv/download`    | Download CSV file |
